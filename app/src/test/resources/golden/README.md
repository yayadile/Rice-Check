# Golden vectors

Reference data for the Kotlin ML port, generated by the scripts in `tools/` (see repo root).
Do not edit by hand; regenerate from the training project instead.

## `svm/`

- `manifest.json`: one entry per case: `name`, `label` (`normal`/`pemutih`),
  `decision` (SVM decision_function value), `class` (0/1).
- `resized/<name>.bin`: exact 256x256 **BGR uint8** image (`cv2.INTER_AREA`) fed to the
  feature extractor. 196,608 bytes.
- `features/<name>.f32`: 8202 little-endian float32 raw features.
- `scaled/<name>.f32`: 8202 float32 after `StandardScaler`.

Feature layout: `[0:6]` GLCM props, `[6:8106]` HOG (L2-Hys), `[8106:8202]` 32-bin BGR hist.

## `yolo/`

- `manifest.json`: `name`, `width`, `height`, `imgsz`, `scale`, `pad_x`, `pad_y`,
  `counts` per class, and `detections` (`xyxy` in original pixels, `conf`, `cls`).
- `images/<name>.jpg`: source detection photos.

Detections come from Ultralytics `predict` at `conf 0.25`, `iou 0.45`, `max_det 1000`.
